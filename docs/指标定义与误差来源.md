# 指标定义与误差来源分析

## 1. 深度指标（只在有效像素上计算）

设预测深度 `p`、真值 `g`、有效像素集合 `V`，`n = |V|`。

| 指标 | 定义 | 为什么用它 | 对什么敏感 |
|---|---|---|---|
| AbsRel | `mean(|p-g| / g)` | 尺度无关，远近目标权重均衡 | 近处误差（分母小） |
| RMSE | `sqrt(mean((p-g)²))` | 惩罚大误差 | 离群点、远距离 |
| SIlog | `100 × std(log p - log g)` | 衡量相对尺度一致性，单目相对深度常用 | 整体尺度偏移 |
| δ<1.25ᵏ | `mean(max(p/g, g/p) < 1.25ᵏ)` | 工程上最直观的「可用比例」 | 分布尾部 |
| 误差分位数 p50/p90/p99 | `|p-g|/g` 的分位数 | 区分「普遍偏一点」和「少数严重错」 | 长尾 |
| 有效覆盖率 | `|V| / 总像素` | **必须与精度一起报**，否则不可比 | 置信度阈值、LRC 剔除 |

**为什么不能只看 AbsRel**：一个只在 80% 容易像素上给预测的系统，AbsRel 一定比在 100% 像素上给预测的系统好看，但后者可能更有用。本项目因此在 `outputs/report.md` 同时给出**共同有效域**对比和 **risk-coverage 曲线**。

## 2. 3D 跟踪指标

- **3D IoU**：两个轴对齐 3D 框交集体积 / 并集体积，用于逐帧贪婪关联。
- **MOTA** = `1 - (FN + FP + IDSW) / (TP + FN)`，同时惩罚漏检、误检和身份切换；可为负。
- **MOTP** = 匹配上的框的平均 IoU，衡量定位质量。
- **IDF1** = `2·IDTP / (2·IDTP + IDFP + IDFN)`，从身份维度衡量轨迹连贯性。
- **IDSW**：同一预测轨迹在相邻帧匹配到不同 GT 身份的次数。
- **DetA / AssA / HOTA（单阈值）**：`DetA = TP/(TP+FP+FN)`，`AssA` 为各 GT 轨迹的关联得分均值，`HOTA = sqrt(DetA·AssA)`。

> 本实现的 HOTA 是**单一 IoU 阈值**下的计算，未做官方的多阈值积分，数值口径与论文不完全等同。报告中明确标注为 `HOTA_single_threshold`。

## 3. 误差来源清单

### 3.1 几何与标定（系统性）
- 相机内参 / 基线误差：深度 `Z = f·B/d`，对 `B` 和 `f` 线性敏感；
- 立体未完全极线校正：本仓库数据已极线校正，真实数据需先做 rectification；
- SfM 外参误差 → 三角化点沿视线方向拉长。

### 3.2 视差量化与匹配（算法性）
- **视差量化**：`Z ∝ 1/d`，远处 `d` 很小，1 像素视差误差就能造成巨大深度误差 → 这就是 `far` 切片最难的原因；
- **弱纹理 / 重复纹理**：代价曲线平坦，WTA 容易选错峰 → `low_texture` 切片；
- **遮挡**：左右视图可见性不同，LRC 会正确剔除，但覆盖率下降；
- **亚像素拟合**：抛物线拟合只在单峰、对称代价曲线附近可靠。

### 3.3 场景退化（数据性）
- 低照度传感器噪声 → 代价体噪声 → `low_light`；
- 运动模糊 → 边缘定位偏移 → `motion_blur`；
- 动态物体 / 双快门不同步 → 左右视图不一致 → `dynamic`。

### 3.4 伪真值源特有
- **SfM 稀疏扩散**：把稀疏点按 16×16 网格取中位数再平滑，会抹平物体边界，产生系统性偏差；
- **相对深度对齐**：单目先验只有相对尺度，用最小二乘 `g ≈ a·rel + b` 对齐到 SfM；若 SfM 点分布不均，`a/b` 会整体偏；
- **置信度口径不一致**：峰值比 / 重投影误差 / 人为常数不是同一把尺子 → 这是等权融合失效的根因。

## 4. 置信度校准

`gt_qc.py` 把有效像素按 confidence 分 5 箱，报告每箱像素数与实测平均 AbsRel。

- **理想**：高置信箱的 AbsRel 单调低于低置信箱；
- **反转**：说明该源的置信度定义与真实误差不相关，不能直接用于加权——此时必须引入源级可靠性标定（见 `方案设计.md` 第 4 节）。

这是真值系统里最容易被忽略的一环：**伪标签的置信度本身也需要被验证**。

## 5. 报告阅读顺序建议

1. 先看第 2 节方案对比，但**连同覆盖率一起看**；
2. 看 2.1 共同有效域，判断融合有没有损害已有精度；
3. 看 2.2 risk-coverage，确定业务该取哪个置信度阈值；
4. 看第 3 节源级权重，理解为什么等权融合会崩；
5. 看第 4 节切片排序，定位算法失效场景；
6. 看第 7 节 hard-case，把图块坐标转成补采清单。
